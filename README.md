# Starry Wall · 今夜留一句

一面面向所有人的弹幕涂鸦墙，将日常记录、自由涂鸦、表白和祝福留在夜色与星空之间。

## 产品方向

- 可拖动、缩放的共享墙面，支持文字留言与简单画笔。
- 新留言以弹幕呈现，随后保存在墙面上，支持回看。
- 祝福可触发烟花或流星雨；自动建议效果，发布者可以修改。
- 支持“接住祝福”、定位分享，以及举报、撤回和防刷屏。
- 声音默认关闭，提供减少动态效果的选项。

## 项目状态

仓库初始化阶段，尚未添加网站实现或确定技术栈。
