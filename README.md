# Starry Wall · 今夜留一句

一面夜色与星空之间的涂鸦墙。写一句心事，画一点喜欢，让祝福化成烟花或流星。

## 本地运行

需要 Node.js 22 或更新版本。没有第三方运行依赖，不需要安装 npm 包。

```powershell
cd D:\starry-wall
npm run dev
```

打开 **http://localhost:4173**。请固定使用这个地址：`localhost`、`127.0.0.1`、不同端口和不同浏览器属于不同的本地数据空间。

## 怎么玩

- **漫游**：拖动墙面、滚轮缩放；手机上单指移动、双指缩放。右侧可以调整比例或回到中心。
- **留下文字**：最多 120 字，选择日常、表白或祝福，挑选颜色。祝福关键词会给出可修改的推荐。
- **随手涂鸦**：直接在墙上画，六种颜色、三档笔宽，支持撤销、重做。双指调整视角不会保存成笔画；确认发布后成为一幅作品，取消则丢弃草稿。
- **送出祝福**：保存成功后才播放烟花或流星雨，同一句祝福分批铺满屏幕，约 5 秒后回到墙上的许愿星。可以跳过、重播或“接住祝福”。
- **我的作品**：回看、定位自己发布的内容。删除操作需要确认，删除后无法撤销。
- **弹幕时刻**：播放当前本地墙面中的文字，可以暂停。示例会标明身份。
- **偏好设置**：减少动态效果、开启可选的祝福音效、隐藏示例。音效默认关闭。
- **键盘**：`T` 写文字，`D` 画画；聚焦墙面后方向键移动，`+` / `-` 缩放，`Home` 回到中心。画笔模式按 `Esc` 返回浏览并保留草稿。

## 保存与边界

作品和偏好保存在当前浏览器的 IndexedDB 中，刷新后恢复。没有服务端、账号或多人同步，内容不会上传。清除网站数据、删除浏览器配置或关闭无痕窗口可能丢失作品；GitHub 只管理代码，不备份浏览器中的作品。

文字编辑器关闭后保留当前会话的草稿；涂鸦切回浏览也保留草稿。**尚未发布的草稿不会跨刷新保存。** 保存失败会保留草稿、展示错误，可以重新发布。示例不计入“我的作品”；“接住祝福”仅保存本机状态，不代表公共人数。

墙面逻辑尺寸为 6000×4000，绘制画布始终与视口一致。文本通过 DOM 安全展示，涂鸦保存为相对坐标笔画，粒子使用独立的视口 Canvas。

## 代码结构

- `src/core.js`：坐标转换、绘画历史、祝福推荐与数据规范。
- `src/wall.js`：墙面、视口绘制、鼠标与触屏手势。
- `src/storage.js`：独立 IndexedDB 存储接口。
- `src/app.js`：创作、收藏、偏好与保存反馈。
- `src/effects.js`：烟花、流星、祝福文字与弹幕。
- `scripts/dev.mjs`：仅向本机开放的静态预览服务，不提供写入接口。

## 验证

```powershell
npm test
npm run test:browser
```

单元测试使用 Node 内置测试运行器。浏览器测试使用本机 Chrome 或 Edge，通过原生 DevTools 协议运行，无需第三方包；可用 `BROWSER_EXECUTABLE` 指定浏览器路径。先运行本地预览，再运行浏览器测试。截图与报告写入已忽略的 `test-results/`，测试使用独立临时浏览器配置，不接触你平时的浏览器数据。
