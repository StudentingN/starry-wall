- Node 内置测试：7 项通过，涵盖墙面坐标转换、指针锚定缩放与边界、撤销重做和分支历史、祝福关键词、涂鸦数据转换、Unicode 字数及无效数据处理、空白位置选择。

- 桌面视口：1440×960；手机视口：390×844。检查并查看了桌面、初始手机墙面、手机编辑器、绘画、烟花和流星截图。

## 浏览器场景

1. 墙面正常渲染，示例与用户作品有明确标记。
2. 实际鼠标事件完成拖动、缩放与回到中心；在手机模拟与桌面尺寸切换后仍通过。
3. 文字发布、IndexedDB 记录、新留言弹幕。
4. 模拟文字保存失败后保留草稿，重试成功；HTML 字符串按文本显示。
5. 烟花完整播放约 5 秒，结束后保留作品；接住状态、重播和跳过。
6. 流星雨正常播放，减少动态效果时使用单句淡入；播放期间焦点位于跳过按钮，背景暂时不可操作，结束后恢复。
7. 实际鼠标绘画、撤销、重做及确认发布。
8. 刷新恢复文字、涂鸦、“接住祝福”状态和我的作品列表。
9. 手机布局、编辑器边界、真实合成触摸事件、双指缩放取消当前笔画；模拟涂鸦保存失败后草稿保留并可重试发布。
10. 取消草稿后不再显示旧笔画，弹幕可暂停并清理。
11. 删除需要确认，确认后本地记录移除。
12. 静态服务不暴露 Git 配置、包配置或通过编码的 Windows 路径绕过访问限制。

## 运行与产物

`npm test` 运行单元测试。先 `npm run dev`，再 `npm run test:browser` 运行浏览器测试。

自动化使用单独创建的临时浏览器配置，不读取日常浏览器资料；测试数据不写入用户正在使用的浏览器。截图和成功报告位于已忽略的 `test-results/`，不上传 GitHub。

## 验证范围

手机检查通过 Chrome 设备尺寸和触摸模拟完成，尚未在实体手机、Safari 或 Firefox 上执行。没有人工试听音效，也没有模拟手机软键盘。多人同步、线上部署、跨设备保存和生产规模压力测试不在本阶段范围内。

本阶段没有部署线上网站；使用固定的 `http://localhost:4173` 预览。已发布作品保存在使用者自己的浏览器；尚未发布的草稿只在当前页面会话内保留。
